# Algorithms

Учебный репозиторий с лабораторными работами на C++ под Visual Studio.

## Что есть в `lab1`

Проект представляет собой консольное меню для работы с объектами предметной области:

- добавление, редактирование и удаление труб и станций;
- сохранение и загрузка данных из файла;
- поиск и пакетные операции;
- соединение станций;
- топологическая сортировка;
- поиск максимального потока;
- поиск кратчайшего пути.

## Сборка

Проект ориентирован на Visual Studio и файлы решений `*.sln` / `*.vcxproj`.

Обычно достаточно:

1. Открыть нужный `.sln` в Visual Studio.
2. Выбрать конфигурацию сборки.
3. Собрать и запустить проект стандартными средствами IDE.
